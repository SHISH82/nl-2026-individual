# 2.4. Рекурсивное восстановление бинарного дерева по результатам обходов (OCaml)

## Постановка

Даны результаты прямого (preorder) и симметричного (inorder) обходов бинарного дерева с уникальными ключами. Требуется восстановить дерево. Дополнительно поддерживается пара «симметричный + обратный (postorder) обход».

**Алгоритм.** Первый элемент прямого обхода — корень. Его позиция в симметричном обходе делит симметричный обход на левое и правое поддеревья; соответствующие части прямого обхода определяются по размерам поддеревьев. Поддеревья восстанавливаются рекурсивно.

**Входные данные.** Два обхода — две строки с консоли или из файла.

**Выходные данные.** Дерево в наглядном текстовом виде, а также обратный обход и обход в ширину для проверки.

**Обработка ошибок.** Разная длина обходов, разные наборы элементов, повторяющиеся ключи, несогласованные обходы.

## Реализация

- Дерево — алгебраический тип `type tree = Empty | Node of string * tree * tree`. Ключи — строки, поэтому подходят и числа, и буквы.
- `build_pre_in pre ino` — рекурсивное восстановление по прямому и симметричному обходам: корень — голова прямого обхода, его позиция `i` в симметричном обходе даёт размер левого поддерева, списки делятся функциями `take` и `drop`, поддеревья строятся рекурсивно.
- `build_in_post ino post` — то же для пары «симметричный + обратный»: корень — последний элемент обратного обхода.
- На каждом шаге проверяется, что части обходов для поддерева содержат одинаковые ключи. Иначе выводится ошибка «обходы несогласованы». До построения проверяются длина обходов, повторы ключей и совпадение наборов.
- Дерево печатается «боком»: корень слева, правое поддерево сверху, каждый уровень с отступом 4 пробела.
- Для проверки по построенному дереву заново считаются все обходы (прямой, симметричный и обратный рекурсивно, в ширину — через очередь `Queue`) и сравниваются с исходными.

Используется только стандартная библиотека OCaml.

## Окружение

- OCaml 4.14 или новее, так как нужен модуль `In_channel` (проверено на OCaml 5.5.2). Программа запускается интерпретатором `ocaml` без компиляции.
- Установка: macOS — `brew install ocaml`, Debian/Ubuntu — `sudo apt install ocaml`, либо через [opam](https://ocaml.org/install).

## Запуск

Из каталога задачи:

```bash
cat data/pre_in.txt
ocaml src/tree.ml pre-in < data/pre_in.txt
cat data/in_post.txt
ocaml src/tree.ml in-post < data/in_post.txt
cat data/letters.txt
ocaml src/tree.ml pre-in < data/letters.txt
ocaml src/tree.ml pre-in < data/chain.txt
ocaml src/tree.ml pre-in < data/single.txt
```

Параметры:

- `pre-in` — на входе прямой и симметричный обходы;
- `in-post` — на входе симметричный и обратный обходы;
- обходы подаются на стандартный ввод двумя строками, ключи через пробел. Можно ввести их с клавиатуры или перенаправить из файла.

## Данные

| Файл                    | Содержимое                                               |
| ----------------------- | -------------------------------------------------------- |
| `data/pre_in.txt`       | прямой `1 2 4 5 3 6` и симметричный `4 2 5 1 3 6` обходы |
| `data/in_post.txt`      | симметричный и обратный обходы того же дерева            |
| `data/letters.txt`      | дерево из 9 узлов с буквенными ключами                   |
| `data/chain.txt`        | вырожденное дерево-цепочка                               |
| `data/single.txt`       | дерево из одного узла                                    |
| `data/diff.txt`         | обходы с разными наборами ключей                         |
| `data/inconsistent.txt` | несогласованные обходы                                   |
| `data/dup.txt`          | повторяющиеся ключи                                      |
| `data/short.txt`        | только одна строка                                       |
