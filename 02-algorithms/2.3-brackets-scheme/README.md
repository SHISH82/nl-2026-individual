# 2.3. Рекурсивная генерация правильных скобочных последовательностей (Scheme)

## Постановка

Дано число n. Требуется сгенерировать все правильные скобочные последовательности из n пар круглых скобок в лексикографическом порядке (`(` < `)`). Дополнительно — рекурсивная проверка произвольной строки на правильность скобочной последовательности.

**Алгоритм.** Рекурсивная функция строит последовательность посимвольно, отслеживая число открытых и закрытых скобок: открывающую скобку можно поставить, пока их меньше n; закрывающую — пока закрытых меньше, чем открытых.

**Входные данные.** Число n (режим генерации) или строка (режим проверки) с консоли.

**Выходные данные.** Все последовательности и их количество (число Каталана `C(n)`); в режиме проверки — результат и позиция первой ошибки.

## Реализация

- `gen open close prefix n` — рекурсивная функция. Когда поставлены все `2n` скобок, она возвращает готовую строку. Иначе склеивает результаты двух ветвей: «поставить `(`», если `open < n`, и «поставить `)`», если `close < open`. Ветвь с `(` идёт первой, поэтому последовательности получаются в лексикографическом порядке.
- `count-seq` — та же рекурсия, но без построения строк, только подсчёт. Используется с ключом `-c` для больших n.
- Для проверки количество сравнивается с числом Каталана `C(n) = (2n)! / ((n+1)!·n!)`, факториал тоже считается рекурсивно.
- `check s i stack` — рекурсивная проверка строки: проход по символам со стеком позиций открытых скобок. Закрывающая скобка при пустом стеке — лишняя. Если в конце стек не пуст, сообщается позиция первой незакрытой скобки. Другие символы считаются ошибкой ввода.
- Вывод переключается в UTF-8 явно, чтобы русский текст выводился правильно при любой локали.

Используется только стандартная библиотека Guile.

## Окружение

- GNU Guile 2.2 или новее (проверено на Guile 3.0.11).
- Установка: macOS — `brew install guile`, Debian/Ubuntu — `sudo apt install guile-3.0`.

При первом запуске Guile компилирует программу и печатает об этом служебное сообщение `;;; note: auto-compilation is enabled`. При следующих запусках его нет.

## Запуск

Из каталога задачи:

```bash
guile src/brackets.scm gen 3
guile src/brackets.scm gen 4
guile src/brackets.scm gen 0
guile src/brackets.scm gen 5 -c
guile src/brackets.scm gen 10 -c
guile src/brackets.scm check "(())()"
guile src/brackets.scm check "(()"
guile src/brackets.scm check "())("
```

Параметры:

- `gen n` — вывести все правильные последовательности из n пар скобок;
- `gen n -c` — вывести только количество;
- `check строка` — проверить строку из скобок `(` и `)`.

## Данные

Входные файлы не нужны: n и строка задаются аргументами.

| Ввод             | Ожидаемый результат                   |
| ---------------- | ------------------------------------- |
| `gen 3`          | 5 последовательностей = C(3)          |
| `gen 4`          | 14 = C(4)                             |
| `gen 0`          | одна пустая последовательность        |
| `gen 10 -c`      | 16796 = C(10)                         |
| `check "(())()"` | правильная                            |
| `check "(()"`    | скобка в позиции 1 не закрыта         |
| `check "())("`   | лишняя закрывающая скобка в позиции 3 |
