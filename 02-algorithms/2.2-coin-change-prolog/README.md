# 2.2. Решение задачи о размене монет через рекурсию (Prolog)

## Постановка

Дана сумма S и набор номиналов монет (каждый номинал доступен в неограниченном количестве). Требуется:

1. найти количество способов разменять сумму S (способы, отличающиеся только порядком монет, считаются одинаковыми);
2. вывести все способы размена;
3. найти способ с минимальным количеством монет.

**Алгоритм.** Рекурсивное отношение: число способов разменять S монетами `[C | Cs]` равно сумме числа способов разменять `S - C` теми же монетами (монета C используется) и числа способов разменять S монетами `Cs` (монета C больше не используется). База: `S = 0` — один способ; `S < 0` или пустой набор — ноль способов.

**Входные данные.** Сумма и список номиналов вводятся с консоли.

**Выходные данные.** Количество способов, список всех способов, минимальный размен. Если размен невозможен, выводится соответствующее сообщение.

## Реализация

- `ways(S, Coins, N)` — рекурсивное отношение из постановки: четыре предложения для базы `S = 0`, пустого набора, отрицательной суммы и общего случая «монету используем / больше не используем». Директива `:- table ways/3.` запоминает уже вычисленные ответы, поэтому большие суммы считаются быстро.
- `way(S, Coins, W)` строит один способ размена. При бэктрекинге Prolog перебирает все способы, их выводит `forall`. Номиналы отсортированы по убыванию, поэтому каждый способ записан от крупных монет к мелким и не повторяется в другом порядке.
- `fewest(S, Coins, Best)` — рекурсивный поиск размена с наименьшим числом монет: для каждой монеты `C ≤ S` берётся лучший размен суммы `S - C`, из вариантов выбирается самый короткий. Тоже с табулированием. Жадный алгоритм здесь не используется: для 6 из {1, 3, 4} он дал бы 4 + 1 + 1, а правильный ответ — 3 + 3.
- Если способов больше 30, список не выводится. Если их не больше 1000, количество дополнительно проверяется перебором всех способов через `findall`.
- Номиналы и сумма задаются аргументами командной строки. Если аргументов нет, программа спрашивает их в консоли.

Используется только SWI-Prolog и его стандартные встроенные предикаты.

## Окружение

- SWI-Prolog 9 или новее (проверено на SWI-Prolog 11.0.0).
- Установка: [swi-prolog.org/download](https://www.swi-prolog.org/download/stable). macOS: `brew install swi-prolog`, Debian/Ubuntu: `sudo apt install swi-prolog`.

## Запуск

Из каталога задачи:

```bash
swipl src/coins.pl 5 1 2 5
swipl src/coins.pl 10 1 2 5
swipl src/coins.pl 6 1 3 4
swipl src/coins.pl 11 2 5
swipl src/coins.pl 3 2
swipl src/coins.pl 100 1 5 10 25 50
swipl src/coins.pl 1000 1 5 10 25 50
swipl src/coins.pl
```

Параметры: первое число — сумма, остальные — номиналы монет. Повторяющиеся номиналы учитываются один раз. Без параметров сумма и номиналы вводятся в консоли.

## Данные

Входные файлы не нужны: сумма и номиналы задаются аргументами или вводятся с консоли.

| Ввод                | Ожидаемый результат                   |
| ------------------- | ------------------------------------- |
| `5 1 2 5`           | 4 способа, минимум 1 монета (5)       |
| `10 1 2 5`          | 10 способов, минимум 2 монеты (5 + 5) |
| `6 1 3 4`           | 4 способа, минимум 2 монеты (3 + 3)   |
| `11 2 5`            | 1 способ: 5 + 2 + 2 + 2               |
| `3 2`               | размен невозможен                     |
| `100 1 5 10 25 50`  | 292 способа                           |
| `1000 1 5 10 25 50` | 801451 способ                         |
