# 2.1. Рекурсивная генерация разбиений множества (Haskell)

## Постановка

Дано конечное множество элементов. Разбиением множества называется представление его в виде объединения непустых попарно непересекающихся подмножеств (блоков). Требуется сгенерировать все разбиения множества.

**Алгоритм.** Рекурсия по элементам: разбиения множества `{x} ∪ S` получаются из каждого разбиения множества `S` либо добавлением `x` в один из существующих блоков, либо добавлением `x` отдельным новым блоком. База рекурсии — пустое множество с единственным пустым разбиением.

**Входные данные.** Элементы множества вводятся с консоли через пробел (или число n — тогда множество `{1..n}`). Необязательный параметр k — выводить только разбиения ровно на k блоков.

**Выходные данные.** Все разбиения, по одному на строку, и их количество (число Белла `B(n)`, а при заданном k — число Стирлинга второго рода `S(n, k)`).

**Обработка ошибок.** Повторяющиеся элементы, некорректное k.

## Реализация

- `partitions :: [a] -> [[[a]]]` — рекурсивная функция: для пустого списка возвращает `[[]]`, иначе строит разбиения остальных элементов и для каждого из них вызывает `add`.
- `add x p` возвращает все способы добавить элемент `x` в разбиение `p`: дописать его в конец каждого блока по очереди или добавить новым блоком `[x]`.
- Элементы обрабатываются с конца списка, поэтому в каждом блоке элементы идут в исходном порядке, а блоки упорядочены по первому элементу.
- Фильтр по числу блоков `k` применяется к готовому списку разбиений. Благодаря ленивости Haskell с ключом `-c` разбиения не печатаются и не хранятся, а только подсчитываются.
- Для проверки количество разбиений сравнивается с числом Белла или Стирлинга, которое считается независимо по рекуррентной формуле `S(n, k) = k·S(n-1, k) + S(n-1, k-1)`.
- Если элементы не заданы аргументами, они читаются из консоли одной строкой.

Используется только стандартная библиотека Haskell (`base`).

## Окружение

- GHC 9.0 или новее (проверено на GHC 9.14.1), программа запускается через `runghc`.
- Установка через [GHCup](https://www.haskell.org/ghcup/) (macOS и Linux):

```bash
curl --proto '=https' --tlsv1.2 -sSf https://get-ghcup.haskell.org | sh
```

## Запуск

Из каталога задачи:

```bash
runghc src/Partitions.hs a b c
echo кот пёс рыба | runghc src/Partitions.hs
runghc src/Partitions.hs -n 4
runghc src/Partitions.hs -n 4 -k 2
runghc src/Partitions.hs -n 5 -k 3 -c
runghc src/Partitions.hs -n 10 -c
runghc src/Partitions.hs -n 0
```

Параметры:

- элементы множества через пробел; если их нет, программа читает строку из консоли;
- `-n N` — множество `{1, 2, …, N}`;
- `-k K` — выводить только разбиения ровно на K блоков;
- `-c` — вывести только количество разбиений.

## Данные

Входные файлы не нужны: элементы задаются аргументами или вводятся с консоли.

| Ввод        | Ожидаемое количество |
| ----------- | -------------------- |
| `a b c`     | 5 = B(3)             |
| `-n 4`      | 15 = B(4)            |
| `-n 4 -k 2` | 7 = S(4, 2)          |
| `-n 5 -k 3` | 25 = S(5, 3)         |
| `-n 10`     | 115975 = B(10)       |
| `-n 0`      | 1 (пустое разбиение) |
