# 3.2. Создание и применение текстового патча (Nim)

## Постановка

Программа работает в двух режимах:

1. `diff old.txt new.txt` — построчно сравнивает два файла и создаёт патч;
2. `apply old.txt file.patch` — применяет патч к исходному файлу и получает новую версию.

**Алгоритм.** Различия вычисляются через наибольшую общую подпоследовательность строк (динамическое программирование). Патч записывается в формате, близком к unified diff: блоки изменений с заголовком `@@ -a,b +c,d @@`, строки контекста начинаются с пробела, удалённые — с `-`, добавленные — с `+`. Число строк контекста задаётся параметром (по умолчанию 3).

**Выходные данные.** Файл патча (режим `diff`) или новый файл (режим `apply`); в консоль — число добавленных и удалённых строк.

**Обработка ошибок.** При применении проверяется совпадение строк контекста и удаляемых строк; при несовпадении выводится номер строки и патч не применяется. Некорректный формат патча.

**Проверка.** Для любой пары файлов `apply(old, diff(old, new)) = new`.

## Реализация

- Таблица `dp[i][j]` — длина наибольшей общей подпоследовательности строк `old[i..]` и `new[j..]`, заполняется с конца. Проход по таблице от начала даёт список операций: строка общая (` `), удалена (`-`) или добавлена (`+`).
- Операции группируются в блоки: вокруг изменений берётся до C строк контекста, а два изменения, между которыми не больше 2C общих строк, попадают в один блок. Так же работает утилита `diff -u`, и заголовки блоков совпадают с её выводом.
- Заголовок `@@ -a,b +c,d @@` содержит номер первой строки и число строк блока в старом и новом файле. Для блока без строк в одном из файлов указывается номер строки перед местом изменения, например `@@ -0,0 +1,3 @@` при добавлении в пустой файл.
- При применении строки старого файла до очередного блока копируются без изменений. Каждая строка контекста и каждая удаляемая строка сверяется со старым файлом, и при расхождении программа сообщает номер строки и останавливается. Добавленные строки вставляются, число строк в блоке сверяется с заголовком.
- Патч выводится в стандартный вывод, поэтому его сохраняют перенаправлением `> файл`. Статистика печатается в стандартный поток ошибок. Патчи совместимы с системной утилитой `patch`.

Используется только стандартная библиотека Nim.

## Окружение

- Nim 2.0 или новее (проверено на Nim 2.4.2).
- Установка: [nim-lang.org/install.html](https://nim-lang.org/install.html), macOS — `brew install nim`, Linux — `curl https://nim-lang.org/choosenim/init.sh -sSf | sh`.

## Запуск

Из каталога задачи:

```bash
nim c -d:release --hints:off -o:bin/patch src/patch.nim
cat data/old.txt
cat data/new.txt
./bin/patch diff data/old.txt data/new.txt > changes.patch
cat changes.patch
./bin/patch apply data/old.txt changes.patch > result.txt
cmp result.txt data/new.txt && echo "файлы одинаковые"
./bin/patch diff data/long_old.txt data/long_new.txt -c 1 > long.patch
cat long.patch
./bin/patch apply data/long_old.txt long.patch > long_result.txt
cmp long_result.txt data/long_new.txt && echo "файлы одинаковые"
./bin/patch diff data/long_old.txt data/long_new.txt -c 0
./bin/patch diff data/old.txt data/old.txt
./bin/patch apply data/wrong.txt changes.patch
```

Параметры:

- `diff старый новый [-c N]` — построить патч, N — число строк контекста (по умолчанию 3);
- `apply старый патч` — применить патч, результат выводится в стандартный вывод.

## Данные

| Файл                                     | Содержимое                                     |
| ---------------------------------------- | ---------------------------------------------- |
| `data/old.txt`, `data/new.txt`           | три строки: одна удалена, одна добавлена       |
| `data/long_old.txt`, `data/long_new.txt` | 40 строк, изменения в начале, середине и конце |
| `data/wrong.txt`                         | файл, к которому патч `old → new` не подходит  |
| `data/empty.txt`                         | пустой файл                                    |
