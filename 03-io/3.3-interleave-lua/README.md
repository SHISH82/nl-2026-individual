# 3.3. Объединение двух файлов с чередованием строк (Lua)

## Постановка

Даны два текстовых файла. Требуется сформировать новый файл, в котором строки исходных файлов чередуются: строка первого, строка второго, строка первого и т. д. Когда один из файлов заканчивается, оставшиеся строки другого дописываются в конец.

**Параметры:** размеры блоков (m строк из первого файла, n строк из второго, по умолчанию 1 и 1), имя выходного файла (по умолчанию — вывод в консоль).

**Выходные данные.** Объединённый текст; в консоль — сколько строк взято из каждого файла.

**Обработка ошибок.** Отсутствующие файлы, некорректные размеры блоков, совпадение выходного файла с одним из входных.

## Реализация

- Аргументы разбираются вручную из таблицы `arg`: два имени файла и необязательные `-m`, `-n`, `-o`.
- Каждый файл читается построчно (`file:lines()`) в таблицу Lua. Символ `\r` в конце строки отбрасывается, поэтому файлы с переводами строк Windows тоже обрабатываются правильно.
- Основной цикл идёт, пока не закончатся оба файла: на каждом шаге берётся до m строк из первого файла и до n из второго. Когда один файл заканчивается, цикл просто добирает строки из другого.
- Результат собирается в таблицу и склеивается через `table.concat`. Он выводится в консоль или записывается в файл `-o`.
- Статистика (сколько строк взято из каждого файла) печатается в стандартный поток ошибок после текста, перед этим буфер вывода сбрасывается.
- Проверяются наличие входных файлов, положительные целые размеры блоков и совпадение выходного файла с входным.

Используется только стандартная библиотека Lua.

## Окружение

- Lua 5.3 или новее (проверено на Lua 5.5.1).
- Установка: [lua.org/download.html](https://www.lua.org/download.html), macOS — `brew install lua`, Debian/Ubuntu — `sudo apt install lua5.4`.

## Запуск

Из каталога задачи:

```bash
cat data/a.txt
cat data/b.txt
lua src/interleave.lua data/a.txt data/b.txt
lua src/interleave.lua data/a.txt data/b.txt -m 2 -n 1
lua src/interleave.lua data/a.txt data/empty.txt
cat data/ru.txt
cat data/en.txt
lua src/interleave.lua data/ru.txt data/en.txt
lua src/interleave.lua data/ru.txt data/en.txt -m 2 -n 2 -o merged.txt
cat merged.txt
```

Параметры:

- два входных файла;
- `-m N` — сколько строк подряд брать из первого файла (по умолчанию 1);
- `-n N` — сколько строк подряд брать из второго файла (по умолчанию 1);
- `-o файл` — записать результат в файл вместо консоли.

## Данные

| Файл             | Содержимое                |
| ---------------- | ------------------------- |
| `data/a.txt`     | строки `a1`, `a2`, `a3`   |
| `data/b.txt`     | строки `b1`, `b2`         |
| `data/ru.txt`    | четыре фразы на русском   |
| `data/en.txt`    | те же фразы на английском |
| `data/empty.txt` | пустой файл               |
