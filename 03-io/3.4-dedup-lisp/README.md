# 3.4. Удаление повторяющихся строк из файла (Common Lisp)

## Постановка

Программа читает текстовый файл и удаляет повторяющиеся строки. В отличие от утилиты `uniq`, входной файл не обязан быть отсортирован.

**Режимы:**

- удаление всех повторов с сохранением первого вхождения и исходного порядка строк (хеш-таблица);
- удаление только подряд идущих повторов.

**Параметры:** игнорирование регистра, игнорирование пробелов в начале и конце строки, имя выходного файла (по умолчанию — вывод в консоль), вывод частоты повторов.

**Выходные данные.** Текст без повторов; в консоль — количество исходных, оставшихся и удалённых строк.

**Обработка ошибок.** Отсутствующий файл, неизвестные параметры.

## Реализация

- Файл читается построчно в кодировке UTF-8 (`with-open-file`, `read-line`), символ `\r` в конце строки отбрасывается. Файл не в UTF-8 даёт понятное сообщение об ошибке.
- Для каждой строки строится ключ сравнения: с `--trim` убираются пробелы и табуляции по краям (`string-trim`), с `--ignore-case` строка переводится в нижний регистр (`string-downcase`). Сама строка выводится в исходном виде.
- Строки собираются в группы — пары «первое вхождение строки, число повторов».
  - В обычном режиме группы хранятся в хеш-таблице `(make-hash-table :test 'equal)` по ключу, поэтому сохраняется первое вхождение и исходный порядок строк, а сортировка не нужна.
  - В режиме `--adjacent` новая группа начинается, когда ключ отличается от ключа предыдущей строки (как у `uniq`).
- `--count` выводит перед каждой строкой число её повторов.
- Результат выводится в консоль или записывается в файл `-o`, статистика печатается в поток ошибок.

Используется только стандартный Common Lisp и функции SBCL для аргументов командной строки и выхода из программы (`sb-ext:*posix-argv*`, `sb-ext:exit`).

## Окружение

- SBCL 2.0 или новее (проверено на SBCL 2.4.0).
- Установка: [sbcl.org/platform-table.html](https://www.sbcl.org/platform-table.html), macOS — `brew install sbcl`, Debian/Ubuntu — `sudo apt install sbcl`.

## Запуск

Из каталога задачи:

```bash
cat data/animals.txt
sbcl --script src/dedup.lisp data/animals.txt
sbcl --script src/dedup.lisp --count data/animals.txt
cat data/adjacent.txt
sbcl --script src/dedup.lisp --adjacent data/adjacent.txt
sbcl --script src/dedup.lisp --adjacent --count data/adjacent.txt
cat data/case.txt
sbcl --script src/dedup.lisp --ignore-case data/case.txt
sbcl --script src/dedup.lisp --trim data/spaces.txt
sbcl --script src/dedup.lisp --count data/log.txt
sbcl --script src/dedup.lisp -o unique.txt data/log.txt
cat unique.txt
```

Параметры:

- `--adjacent` — удалять только подряд идущие повторы;
- `--ignore-case` — не различать регистр букв;
- `--trim` — не учитывать пробелы и табуляции в начале и конце строки;
- `--count` — выводить число повторов каждой строки;
- `-o файл` — записать результат в файл вместо консоли.

## Данные

| Файл                | Содержимое                                       |
| ------------------- | ------------------------------------------------ |
| `data/animals.txt`  | `кот`, `пёс`, `кот`, `рыба`, `пёс`               |
| `data/adjacent.txt` | повторы подряд и вразброс: `a a b a a a c`       |
| `data/case.txt`     | одно слово в разном регистре                     |
| `data/spaces.txt`   | одно слово с пробелами и табуляцией по краям     |
| `data/log.txt`      | журнал событий сервера с повторяющимися записями |
| `data/empty.txt`    | пустой файл                                      |
