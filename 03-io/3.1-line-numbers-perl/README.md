# 3.1. Нумерация строк текстового файла (Perl)

## Постановка

Программа читает текстовый файл (или стандартный ввод, если файл не указан) и выводит его строки с номерами.

**Параметры командной строки:**

- начальный номер (по умолчанию 1) и шаг нумерации (по умолчанию 1);
- ширина поля номера и разделитель между номером и строкой;
- режим пропуска пустых строк (пустые строки выводятся, но не нумеруются);
- имя выходного файла (по умолчанию — вывод в консоль).

**Выходные данные.** Пронумерованный текст; в консоль — количество обработанных и пронумерованных строк.

**Обработка ошибок.** Отсутствующий или недоступный для чтения файл, некорректные значения параметров.

## Реализация

- Аргументы разбираются вручную в цикле. Так все сообщения об ошибках получаются на русском, а неизвестные параметры отлавливаются явно.
- Ввод и вывод работают в UTF-8 (`use open qw(:std :encoding(UTF-8))`), аргументы декодируются через модуль `Encode`, поэтому разделитель может содержать любые символы.
- Строки читаются по одной из файла или из `STDIN`. Номер печатается через `printf "%*d"` с заданной шириной поля.
- В режиме `-b` строка из одних пробелов или пустая выводится без номера (только отступ и разделитель) и не увеличивает счётчик.
- Итоговая статистика печатается в `STDERR`, поэтому при выводе в файл или в конвейер она не смешивается с текстом.
- Проверяются параметры (ненулевой шаг, ширина от 1 до 20), доступность входного и выходного файлов, совпадение выходного файла с входным.

Используются только стандартные модули Perl (`Encode` входит в поставку).

## Окружение

- Perl 5.10 или новее (проверено на Perl 5.34.1). В macOS и большинстве дистрибутивов Linux Perl уже установлен.
- Установка при необходимости: [perl.org/get.html](https://www.perl.org/get.html).

## Запуск

Из каталога задачи:

```bash
cat data/poem.txt
perl src/numlines.pl data/poem.txt
perl src/numlines.pl -b data/poem.txt
perl src/numlines.pl -s 10 -i 10 -w 4 -d " | " -b data/poem.txt
perl src/numlines.pl -s 100 -i -5 -w 3 -d ". " data/text.txt
cat data/poem.txt | perl src/numlines.pl -d ": "
perl src/numlines.pl -b -d " | " -o numbered.txt data/poem.txt
cat numbered.txt
```

Параметры:

- `-s N` — начальный номер (по умолчанию 1);
- `-i N` — шаг нумерации, может быть отрицательным (по умолчанию 1);
- `-w N` — ширина поля номера (по умолчанию 6);
- `-d текст` — разделитель между номером и строкой (по умолчанию табуляция);
- `-b` — не нумеровать пустые строки;
- `-o файл` — записать результат в файл вместо консоли;
- файл — входной файл; если не указан, текст читается со стандартного ввода.

## Данные

| Файл             | Содержимое                                                                       |
| ---------------- | -------------------------------------------------------------------------------- |
| `data/poem.txt`  | две строфы стихотворения А. С. Пушкина «Зимнее утро» с пустой строкой между ними |
| `data/text.txt`  | короткий текст на латинице с двумя пустыми строками                              |
| `data/empty.txt` | пустой файл                                                                      |
