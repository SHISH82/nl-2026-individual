# 1.1. Параллельное вычисление матрицы расстояний Хэмминга (Rust)

## Постановка

Дан набор из N строк одинаковой длины. Расстоянием Хэмминга между двумя строками называется количество позиций, в которых символы этих строк различаются. Требуется построить матрицу D размера N×N, где `D[i][j]` — расстояние Хэмминга между строками `i` и `j`.

**Входные данные.** Текстовый файл, в каждой непустой строке которого записано одно слово. Число потоков T задаётся аргументом командной строки (по умолчанию — число ядер процессора).

**Параллельная обработка.** Строки матрицы распределяются между T потоками. Каждый поток вычисляет только свои строки матрицы и записывает результат в свою, не пересекающуюся с другими, область памяти, поэтому синхронизация при записи не требуется. Главный поток дожидается завершения всех рабочих потоков и собирает результат. Используются только потоки стандартной библиотеки (`std::thread`).

**Выходные данные.** Матрица расстояний, выведенная в консоль или в файл в виде выровненной таблицы. Дополнительно выводится время вычисления в однопоточном и многопоточном режимах и проверка совпадения результатов.

**Обработка ошибок.** Если строки имеют разную длину, программа сообщает номер первой некорректной строки и завершается. Пустой файл и отсутствие файла также обрабатываются с выводом сообщения.

## Реализация

- Матрица хранится в одном векторе длины N·N.
- Вектор делится на T непрерывных кусков по `ceil(N / T)` строк матрицы с помощью `chunks_mut`. Каждый кусок передаётся своему потоку, поэтому потоки пишут в разные участки памяти, а компилятор проверяет это на этапе сборки.
- Потоки запускаются через `std::thread::scope`: все они гарантированно завершаются до выхода из блока, и им можно безопасно передать ссылку на общий список строк только для чтения.
- Для сравнения та же матрица считается последовательно, результаты сравниваются, выводится время и ускорение.
- Режим `gen` создаёт файл из случайных двоичных строк для проверки на больших данных (генератор xorshift, без внешних библиотек).

Внешние библиотеки не используются, в `Cargo.toml` нет зависимостей.

## Окружение

- Rust 1.63 или новее, так как нужен `std::thread::scope` (проверено на Rust 1.100.0).
- Установка: https://rustup.rs

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

## Запуск

Из каталога задачи:

```bash
cargo build --release
./target/release/hamming data/words.txt
./target/release/hamming data/words.txt -t 2
./target/release/hamming data/big.txt -t 8 -o matrix.txt
./target/release/hamming gen 3000 256 > data/big.txt
```

Параметры:
- `-t N` — число потоков (по умолчанию — число ядер процессора);
- `-o файл` — записать матрицу в файл. Без этого параметра матрица выводится в консоль, если в ней не больше 20 строк.

## Данные

| Файл | Содержимое |
|---|---|
| `data/words.txt` | 3 двоичные строки длины 5 |
| `data/names.txt` | 3 слова длины 7 |
| `data/big.txt` | 3000 случайных двоичных строк длины 256 |
| `data/bad.txt` | строки разной длины |
| `data/empty.txt` | пустой файл |

## Пример работы

```
$ ./target/release/hamming data/words.txt -t 2
0 2 3
2 0 5
3 5 0
строк: 3, длина: 5
последовательно: 0.00 мс
параллельно, потоков 2: 0.11 мс
ускорение: 0.00
результаты совпадают: да
```

На трёх строках запуск потоков занимает больше времени, чем само вычисление, поэтому ускорения нет.

```
$ ./target/release/hamming data/names.txt
0 3 3
3 0 4
3 4 0
```

Большие данные (Apple M-серии, 8 ядер):

```
$ ./target/release/hamming data/big.txt -t 8
матрица 3000x3000 слишком большая для консоли, укажите -o <файл>
строк: 3000, длина: 256
последовательно: 427.39 мс
параллельно, потоков 8: 74.03 мс
ускорение: 5.77
результаты совпадают: да
```

| Потоков | Время, мс | Ускорение |
|---|---|---|
| 1 | 375 | 1.0 |
| 2 | 210 | 1.8 |
| 4 | 96 | 3.8 |
| 8 | 74 | 5.1 |

Ошибки:

```
$ ./target/release/hamming data/bad.txt
Ошибка: строка 4: длина 4, ожидалось 5

$ ./target/release/hamming data/empty.txt
Ошибка: в файле нет строк

$ ./target/release/hamming nofile.txt
Ошибка: не удалось открыть файл nofile.txt

$ ./target/release/hamming data/words.txt -t 0
Ошибка: число потоков должно быть положительным целым числом
```
