# 1.4. Параллельное построение матрицы совместной встречаемости слов (D)

## Постановка

Дан текст. Словом считается непрерывная последовательность букв (латиница и кириллица), регистр не учитывается. Два слова встречаются совместно, если расстояние между их позициями в тексте не превышает K (размер окна), при этом пара слова с самим собой в той же позиции не учитывается. Требуется построить симметричную матрицу совместной встречаемости размера V×V, где V — число различных слов, а элемент `C[a][b]` равен числу совместных появлений слов `a` и `b`.

**Входные данные.** Текстовый файл; размер окна K и число потоков T — аргументы командной строки.

**Параллельная обработка.** Последовательность слов делится на T частей. Каждый поток считает пары, начинающиеся в его части (окно может заходить в соседнюю часть только на чтение), и накапливает результат в собственном ассоциативном массиве. После завершения потоков частичные результаты объединяются. Используется `std.parallelism` или `core.thread` из стандартной библиотеки.

**Выходные данные.** Матрица (словарь отсортирован по алфавиту) записывается в файл в виде таблицы; в консоль выводятся N самых частых пар и время работы.

**Обработка ошибок.** Отсутствие файла, текст без слов, некорректные значения K и T.

## Реализация

- Текст читается целиком (`readText`) и разбирается по символам Unicode: буквы (`std.uni.isAlpha`) переводятся в нижний регистр и собираются в слова, остальные символы считаются разделителями.
- Словарь — отсортированный список различных слов. Каждое слово текста заменяется своим номером в словаре, дальше работа идёт с массивом чисел.
- Пара слов с номерами `a ≤ b` хранится в ассоциативном массиве `uint[ulong]` по ключу `a·V + b`. Для каждой позиции `i` учитываются слова на позициях `i+1 … i+K`, поэтому каждая пара считается один раз. Одно и то же слово на разных позициях попадает на диагональ матрицы.
- Массив номеров делится на T частей `[p·n/T, (p+1)·n/T)`. Части обрабатываются через `TaskPool.parallel` из `std.parallelism`, каждая — в свой ассоциативный массив. Окно последней позиции части может заходить в следующую часть, но только на чтение.
- После параллельного цикла частичные массивы складываются в общий. Для сравнения та же задача решается последовательно, результаты сравниваются, выводится время.
- Матрица выводится в консоль, если в словаре не больше 12 слов, иначе записывается в файл ключом `-o` (для словаря до 2000 слов).
- Режим `gen` создаёт текст из 40 русских слов, где слова из начала списка встречаются чаще.

Используется только стандартная библиотека D (Phobos).

## Окружение

- Компилятор LDC 1.30 или новее либо DMD 2.100 или новее (проверено на LDC 1.43.0).
- Установка: [dlang.org/download](https://dlang.org/download.html), например скрипт установки:

```bash
curl -fsS https://dlang.org/install.sh | bash -s ldc
```

## Запуск

Из каталога задачи:

```bash
ldc2 -O3 -od=obj -of=bin/cooc src/cooc.d
cat data/cat.txt
./bin/cooc data/cat.txt -k 1
./bin/cooc data/cat.txt -k 2 -t 2
./bin/cooc data/cat.txt -k 3
cat data/case.txt
./bin/cooc data/case.txt -k 1
./bin/cooc gen 3000000 > data/big.txt
head -2 data/big.txt
./bin/cooc data/big.txt -k 5 -t 1 -top 5
./bin/cooc data/big.txt -k 5 -t 2 -top 5
./bin/cooc data/big.txt -k 5 -t 4 -top 5
./bin/cooc data/big.txt -k 5 -t 8 -top 5
./bin/cooc data/big.txt -k 5 -o matrix.txt
wc -l matrix.txt
```

Параметры:

- `-k K` — размер окна (по умолчанию 2);
- `-t N` — число потоков (по умолчанию — число ядер процессора);
- `-top N` — сколько самых частых пар вывести (по умолчанию 10);
- `-o файл` — записать матрицу в файл.

## Данные

| Файл               | Содержимое                                                 |
| ------------------ | ---------------------------------------------------------- |
| `data/cat.txt`     | «кот ест рыбу кот спит»                                    |
| `data/case.txt`    | одно слово в разном регистре и со знаками препинания       |
| `data/nowords.txt` | текст без слов (только цифры и знаки)                      |
| `data/empty.txt`   | пустой файл                                                |
| `data/big.txt`     | создаётся командой `./bin/cooc gen 3000000 > data/big.txt` |
