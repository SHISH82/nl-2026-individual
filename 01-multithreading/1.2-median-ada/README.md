# 1.2. Параллельная медианная фильтрация числового сигнала (Ada)

## Постановка

Дан числовой сигнал — последовательность вещественных чисел `x[1..n]`. Медианный фильтр с нечётным размером окна W заменяет каждое значение `x[i]` медианой значений в окне `x[i-k..i+k]`, где `k = (W-1)/2`. На границах сигнала недостающие значения заменяются крайним значением сигнала.

**Входные данные.** Текстовый файл с числами (через пробелы или переводы строк). Размер окна W и число задач T передаются аргументами командной строки.

**Параллельная обработка.** Сигнал делится на T непрерывных отрезков. Каждый отрезок обрабатывается отдельной задачей Ada (`task type`). Задачи читают общий входной массив и записывают результат каждая в свой диапазон выходного массива. Главная программа дожидается завершения всех задач.

**Выходные данные.** Отфильтрованный сигнал в консоль или в файл; проверка совпадения с результатом последовательной фильтрации; время работы.

**Обработка ошибок.** Чётный или неположительный размер окна, нечисловые значения во входном файле, пустой сигнал.

## Реализация

- Сигнал читается построчно, каждое число разбирается через `Float'Value`. При ошибке выводится номер значения в файле.
- Медиана в окне: значения окна копируются в локальный массив с повтором крайних элементов на границах, массив сортируется вставками, берётся средний элемент.
- `task type Worker` с входом `Start (First, Last)`. Главная программа создаёт массив из T задач и через рандеву передаёт каждой её отрезок `[(K-1)·N/T + 1, K·N/T]`.
- Массив задач объявлен внутри процедуры `Run_Parallel`. По правилам Ada процедура не завершается, пока не завершатся все её задачи, поэтому отдельное ожидание не нужно.
- Задачи пишут в разные элементы общего выходного массива, поэтому защищённые объекты и блокировки не требуются.
- Для проверки сигнал фильтруется ещё и последовательно, массивы сравниваются, выводится время (`Ada.Real_Time`).
- Режим `gen` создаёт тестовый сигнал: синусоида с импульсными выбросами ±50 в 5 % точек.

Используется только стандартная библиотека Ada.

## Окружение

- Компилятор GNAT с поддержкой Ada 2012 и gprbuild (проверено на GNAT 16.2.0, GPRbuild 26.0.0).
- macOS и Linux: менеджер пакетов [Alire](https://alire.ada.dev), затем выбор компилятора:

```bash
alr toolchain --select gnat_native gprbuild
```

- Linux (Debian/Ubuntu): `sudo apt install gnat gprbuild`.

## Запуск

Из каталога задачи:

```bash
gprbuild -P median.gpr
cat data/signal.txt
./bin/median data/signal.txt 3 4
./bin/median data/signal.txt 5 2
cat data/noise.txt
./bin/median data/noise.txt 3
cat data/fractions.txt
./bin/median data/fractions.txt 3 2
./bin/median gen 1000000 > data/big.txt
head -8 data/big.txt
./bin/median data/big.txt 15 1
./bin/median data/big.txt 15 2
./bin/median data/big.txt 15 4
./bin/median data/big.txt 15 8
./bin/median data/big.txt 15 8 -o result.txt
head -8 result.txt
```

Аргументы: `median <файл> <окно> [задачи] [-o выходной_файл]`.

- окно — нечётное положительное число;
- задачи — число задач Ada, по умолчанию равно числу ядер процессора и уменьшается до длины сигнала, если она меньше;
- `-o файл` — записать результат в файл, по одному значению в строке. Без этого параметра результат выводится в консоль, если в сигнале не больше 50 значений.

## Данные

| Файл                 | Содержимое                                                   |
| -------------------- | ------------------------------------------------------------ |
| `data/signal.txt`    | `1 5 2 8 3 9 4`                                              |
| `data/noise.txt`     | постоянный сигнал с одним выбросом: `1 1 1 100 1 1 1`        |
| `data/fractions.txt` | дробные и отрицательные значения                             |
| `data/bad.txt`       | нечисловое значение                                          |
| `data/empty.txt`     | пустой файл                                                  |
| `data/big.txt`       | создаётся командой `./bin/median gen 1000000 > data/big.txt` |
