# 1.3. Параллельный поиск локальных максимумов матрицы (Julia)

## Постановка

Дана числовая матрица размера M×N. Элемент называется локальным максимумом, если он строго больше всех своих соседей (до 8 соседей по горизонтали, вертикали и диагоналям; у элементов на границе соседей меньше). Требуется найти все локальные максимумы.

**Входные данные.** Текстовый файл: каждая строка файла — строка матрицы, числа разделены пробелами. Число потоков задаётся при запуске Julia (`julia -t T`).

**Параллельная обработка.** Строки матрицы распределяются между потоками (`Threads.@spawn`). Каждый поток собирает найденные максимумы в собственный локальный список, после завершения всех потоков списки объединяются и сортируются. Общий список во время работы потоков не изменяется, поэтому гонок данных нет.

**Выходные данные.** Количество локальных максимумов и их список в виде `(строка, столбец) = значение`; время работы в однопоточном и многопоточном режимах.

**Обработка ошибок.** Строки разной длины, нечисловые значения, пустая матрица.

## Реализация

- Матрица читается построчно, каждое число разбирается через `tryparse(Float64, ...)`. Строки разной длины и нечисловые значения дают сообщение с номером строки.
- `ismax(m, i, j)` проверяет до 8 соседей элемента. Элемент считается максимумом, только если он строго больше каждого существующего соседа, поэтому равные соседи (плато) максимумами не считаются, а элемент матрицы 1×1 — считается.
- Строки делятся на T непрерывных блоков `[(p-1)·M/T + 1, p·M/T]`, T = `Threads.nthreads()`. Для каждого блока запускается задача `Threads.@spawn`, которая собирает координаты в свой вектор и возвращает его.
- Главный поток получает результаты через `fetch`, объединяет их (`reduce(vcat, ...)`) и сортирует. Общих изменяемых данных у задач нет, поэтому блокировки не нужны.
- Для сравнения тот же поиск выполняется последовательно, результаты сравниваются. Время каждого варианта — лучшее из 5 запусков: первый запуск в Julia включает JIT-компиляцию и не отражает скорость самого поиска.
- Режим `gen` создаёт матрицу случайных целых чисел от 0 до 999 для проверки на больших данных.

Используется только стандартная библиотека Julia.

## Окружение

- Julia 1.3 или новее, так как нужен `Threads.@spawn` (проверено на Julia 1.13.4).
- Установка через [juliaup](https://julialang.org/downloads/) (macOS и Linux):

```bash
curl -fsSL https://install.julialang.org | sh
```

## Запуск

Из каталога задачи:

```bash
cat data/small.txt
julia -t 4 src/localmax.jl data/small.txt
cat data/peak.txt
julia -t 4 src/localmax.jl data/peak.txt
cat data/plateau.txt
julia -t 4 src/localmax.jl data/plateau.txt
julia src/localmax.jl gen 2000 2000 > data/big.txt
julia -t 1 src/localmax.jl data/big.txt
julia -t 2 src/localmax.jl data/big.txt
julia -t 4 src/localmax.jl data/big.txt
julia -t 8 src/localmax.jl data/big.txt
julia -t 8 src/localmax.jl data/big.txt -o maxima.txt
head -5 maxima.txt
```

Параметры:

- `-t N` — параметр самой Julia, число потоков (без него используется 1 поток, `-t auto` — по числу ядер);
- `-o файл` — записать список максимумов в файл, по одному в строке в виде `строка столбец значение`. Без этого параметра список выводится в консоль, если в нём не больше 50 элементов.

## Данные

| Файл                 | Содержимое                                                              |
| -------------------- | ----------------------------------------------------------------------- |
| `data/small.txt`     | матрица 3×3 с четырьмя максимумами в углах                              |
| `data/peak.txt`      | матрица 3×3 с одним максимумом в центре                                 |
| `data/plateau.txt`   | плато из равных значений, максимумов нет                                |
| `data/single.txt`    | матрица 1×1                                                             |
| `data/fractions.txt` | дробные и отрицательные значения                                        |
| `data/ragged.txt`    | строки разной длины                                                     |
| `data/bad.txt`       | нечисловое значение                                                     |
| `data/empty.txt`     | пустой файл                                                             |
| `data/big.txt`       | создаётся командой `julia src/localmax.jl gen 2000 2000 > data/big.txt` |
