# 5.3. Markdown-таблица → LaTeX-таблица (F#)

## Постановка

Преобразовать таблицы в формате Markdown (GitHub Flavored Markdown) в таблицы LaTeX (окружение `tabular`).

**Требования:**

- разбор строки-разделителя с выравниванием столбцов: `:---` → `l`, `:---:` → `c`, `---:` → `r`;
- крайние символы `|` в строках необязательны, экранированный `\|` внутри ячейки не является разделителем;
- экранирование специальных символов LaTeX: `& % $ # _ { } ~ ^ \`;
- преобразование встроенной разметки: `**текст**` → `\textbf{текст}`, `*текст*` → `\textit{текст}`, `` `код` `` → `\texttt{код}`;
- заголовок таблицы выделяется жирным, строки разделяются `\hline`;
- по параметру таблица оборачивается в окружение `table` с подписью `\caption`;
- если в файле несколько таблиц, преобразуется каждая.

**Обработка ошибок.** Отсутствие строки-разделителя, разное количество ячеек в строках (с указанием номера строки).

## Реализация

- `findTables` ищет таблицы: блок подряд идущих непустых строк, содержащих `|`. Обычный текст между таблицами пропускается, поэтому в одном документе может быть несколько таблиц.
- `splitCells` делит строку на ячейки посимвольно: `|` — разделитель, `\|` — символ внутри ячейки. Крайние `|` отбрасываются, если они есть.
- Вторая строка таблицы должна быть разделителем (`:---`, `:---:`, `---:`), из неё берётся выравнивание столбцов для `tabular`. Если разделителя нет или в строке другое число ячеек, выводится ошибка с номером строки.
- `convertInline` находит регулярным выражением `` `код` ``, `**жирный**` и `*курсив*` и превращает их в `\texttt`, `\textbf` и `\textit`. Текст между ними и внутри них экранируется функцией `escape`, поэтому спецсимволы LaTeX (`& % $ # _ { } ~ ^ \ |`) не ломают результат.
- Заголовок выводится через `\textbf`, строки разделяются `\hline`. С ключом `--table` (или `--caption`) таблица оборачивается в `table` с `\centering` и `\caption`.
- Результат выводится в консоль или записывается в файл `-o` в кодировке UTF-8. Число найденных таблиц печатается в поток ошибок.

Используется только стандартная библиотека F# и .NET.

## Окружение

- .NET SDK 6 или новее, в него входит F# Interactive (проверено на .NET SDK 7.0.308). Программа запускается как скрипт через `dotnet fsi`, без отдельной компиляции.
- Установка: [dotnet.microsoft.com/download](https://dotnet.microsoft.com/download), macOS — `brew install --cask dotnet-sdk`.
- Для компиляции результата нужен LaTeX с поддержкой русского языка, например `\usepackage[russian]{babel}` в преамбуле.

## Запуск

Из каталога задачи:

```bash
cat data/table.md
dotnet fsi src/MdToLatex.fsx data/table.md
cat data/markup.md
dotnet fsi src/MdToLatex.fsx data/markup.md
cat data/two_tables.md
dotnet fsi src/MdToLatex.fsx data/two_tables.md
dotnet fsi src/MdToLatex.fsx data/table.md --table --caption "Результаты экзамена"
dotnet fsi src/MdToLatex.fsx data/two_tables.md --table -o tables.tex
cat tables.tex
```

Параметры:

- `--table` — обернуть каждую таблицу в окружение `table`;
- `--caption текст` — добавить подпись `\caption` (включает `--table`);
- `-o файл` — записать результат в файл вместо консоли.
