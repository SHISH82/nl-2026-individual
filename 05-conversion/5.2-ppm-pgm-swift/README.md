# 5.2. PPM → PGM (Swift)

## Постановка

Преобразовать цветное изображение в формате PPM в полутоновое изображение в формате PGM.

**Требования:**

- поддержка текстового (`P3`) и двоичного (`P6`) PPM; выход — текстовый (`P2`) или двоичный (`P5`) PGM;
- собственный разбор заголовка: комментарии `#`, произвольные пробельные символы, `maxval` до 65535 (1 или 2 байта на канал);
- способы вычисления яркости: взвешенная сумма по ITU-R BT.601 `Y = 0.299·R + 0.587·G + 0.114·B` (по умолчанию), среднее арифметическое, `(max + min) / 2`;
- используется только `Foundation` для чтения и записи файлов.

**Выходные данные.** PGM-файл; в консоль — размеры изображения и формат.

**Обработка ошибок.** Неверная сигнатура, некорректный заголовок, недостаточное количество данных пикселей, значения больше `maxval`.

## Реализация

- Файл читается целиком в массив байтов `[UInt8]`. Для чтения и записи используются функции стандартной библиотеки C (`fopen`, `fread`, `fwrite`), которые Swift подключает через модуль `Darwin` на macOS или `Glibc` на Linux. Foundation не нужен, поэтому программа собирается одной командой `swiftc` без внешних зависимостей.
- Структура `Reader` разбирает заголовок по байтам: пропускает пробельные символы и комментарии от `#` до конца строки и читает сигнатуру, ширину, высоту и `maxval`.
- Пиксели P3 читаются как текстовые числа. В P6 после `maxval` пропускается один пробельный символ, дальше идут байты: по одному на канал при `maxval < 256` и по два (старший байт первым) при большем `maxval`.
- Яркость считается одним из трёх способов: `luma` (0.299·R + 0.587·G + 0.114·B, по умолчанию), `avg` ((R + G + B) / 3) или `light` ((max + min) / 2) — с округлением до целого. `maxval` сохраняется.
- По умолчанию P3 превращается в P2, а P6 в P5. Ключи `--ascii` и `--binary` задают формат явно. P2 записывается по 12 значений в строке, P5 — байтами.
- Проверяются сигнатура, заголовок (положительные размеры, `maxval` от 1 до 65535), достаточность данных пикселей и значения больше `maxval`.

Используется только стандартная библиотека Swift и стандартная библиотека C платформы.

## Окружение

- Swift 5.7 или новее (проверено на Swift 6.0.2).
- Установка: macOS — Xcode или Command Line Tools (`xcode-select --install`), Linux — [swift.org/install](https://www.swift.org/install/).

## Запуск

Из каталога задачи:

```bash
mkdir -p bin
swiftc -O src/ppm2pgm.swift -o bin/ppm2pgm
cat data/two.ppm
./bin/ppm2pgm data/two.ppm two.pgm --ascii
cat two.pgm
./bin/ppm2pgm data/two.ppm two_avg.pgm --method avg
cat two_avg.pgm
./bin/ppm2pgm data/two.ppm two_light.pgm --method light
cat two_light.pgm
cat data/small.ppm
./bin/ppm2pgm data/small.ppm small.pgm
cat small.pgm
./bin/ppm2pgm data/small_bin.ppm small_bin.pgm --ascii
cmp small.pgm small_bin.pgm && echo "P3 и P6 дают одинаковый результат"
./bin/ppm2pgm data/gradient.ppm gradient.pgm
file data/gradient.ppm gradient.pgm
./bin/ppm2pgm data/deep.ppm deep.pgm --ascii
cat deep.pgm
```

Параметры:

- входной PPM-файл и выходной PGM-файл;
- `--ascii` — записать текстовый PGM (P2), `--binary` — двоичный (P5); по умолчанию формат соответствует входному;
- `--method luma|avg|light` — способ вычисления яркости (по умолчанию `luma`).

## Данные

| Файл                 | Содержимое                                         |
| -------------------- | -------------------------------------------------- |
| `data/two.ppm`       | P3, 2×1: красный и синий пиксель, с комментарием   |
| `data/small.ppm`     | P3, 4×3: 12 разных цветов, комментарии в заголовке |
| `data/small_bin.ppm` | то же изображение в формате P6                     |
| `data/gradient.ppm`  | P6, 256×128: цветной градиент                      |
| `data/deep.ppm`      | P6, 2×2, `maxval` 65535 (2 байта на канал)         |
| `data/broken.ppm`    | P6 с недостающими данными пикселей                 |
| `data/wrong.pgm`     | файл PGM вместо PPM                                |
