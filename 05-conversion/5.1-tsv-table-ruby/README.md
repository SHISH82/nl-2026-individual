# 5.1. TSV → текстовая таблица (Ruby)

## Постановка

Преобразовать файл в формате TSV (значения разделены символом табуляции, первая строка — заголовок) в текстовую таблицу с рамками для вывода в консоль или файл.

**Требования:**

- ширина столбцов вычисляется по самому длинному значению с учётом Unicode-символов;
- числа выравниваются по правому краю, текст — по левому;
- строки с меньшим числом полей дополняются пустыми ячейками;
- поддерживаются escape-последовательности `\t`, `\n`, `\\` внутри полей;
- стиль рамки: ASCII (`+`, `-`, `|`) или Unicode (`┌`, `─`, `┼`, `│`).

**Обработка ошибок.** Пустой файл, строки с большим числом полей, чем в заголовке (выводится предупреждение с номером строки).

## Реализация

- Файл читается целиком в кодировке UTF-8. Каждая строка делится по табуляции через `split("\t", -1)`, поэтому пустые поля в конце строки сохраняются.
- В каждом поле раскрываются escape-последовательности: `\t` — табуляция, `\n` — перевод строки, `\\` — обратная косая черта. Табуляция внутри ячейки выводится четырьмя пробелами, а поле с `\n` занимает в таблице несколько строк.
- Строки короче заголовка дополняются пустыми ячейками. У строк длиннее заголовка лишние поля отбрасываются с предупреждением, где указан номер строки.
- Ширина столбца — длина самой длинной строки ячейки в символах (`String#length` считает символы, а не байты), поэтому кириллица выравнивается правильно.
- Число (целое или дробное, с точкой или запятой) прижимается вправо (`rjust`), текст и заголовки — влево (`ljust`).
- Рамка строится по таблице символов: `ASCII` или `UNICODE`. Таблица выводится в консоль или записывается в файл `-o`, статистика печатается в поток ошибок.

Используется только стандартная библиотека Ruby.

## Окружение

- Ruby 2.6 или новее (проверено на Ruby 2.6.10, входит в macOS).
- Установка: [ruby-lang.org/ru/documentation/installation](https://www.ruby-lang.org/ru/documentation/installation/), macOS — `brew install ruby`, Debian/Ubuntu — `sudo apt install ruby`.

## Запуск

Из каталога задачи:

```bash
cat data/people.tsv
ruby src/tsv2table.rb data/people.tsv
ruby src/tsv2table.rb data/people.tsv --unicode
ruby src/tsv2table.rb data/products.tsv --unicode
ruby src/tsv2table.rb data/ragged.tsv
cat data/escapes.tsv
ruby src/tsv2table.rb data/escapes.tsv --unicode
ruby src/tsv2table.rb data/products.tsv -o table.txt
cat table.txt
```

Параметры:

- `--unicode` — рамка из символов Unicode (по умолчанию ASCII);
- `-o файл` — записать таблицу в файл вместо консоли.

## Данные

| Файл                | Содержимое                                                         |
| ------------------- | ------------------------------------------------------------------ |
| `data/people.tsv`   | пример из постановки: имя, возраст, город                          |
| `data/products.tsv` | товары с ценами: кириллица, дробные числа с запятой, пустые ячейки |
| `data/ragged.tsv`   | строки с недостающими полями и строка с лишним полем               |
| `data/escapes.tsv`  | поля с `\\`, `\t` и `\n`                                           |
| `data/empty.tsv`    | пустой файл                                                        |
