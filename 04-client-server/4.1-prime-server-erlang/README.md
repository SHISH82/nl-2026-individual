# 4.1. Сервер для проверки числа на простоту (Erlang)

## Постановка

Клиент отправляет серверу целые числа, сервер для каждого числа определяет, является ли оно простым. Сервер и консольный клиент реализованы на одном языке, взаимодействие идёт по TCP, сервер обслуживает нескольких клиентов одновременно, порт задаётся аргументом командной строки.

**Протокол (текстовый, построчный):**

- запрос — целое число;
- ответ `PRIME` — число простое;
- ответ `COMPOSITE d` — число составное, `d` — наименьший нетривиальный делитель;
- ответ `NEITHER` — для чисел 0 и 1;
- ответ `ERROR <описание>` — некорректный ввод (не число, отрицательное число);
- команда `QUIT` завершает сеанс.

**Алгоритм.** Проверка делителей вида `6k ± 1` до квадратного корня из числа; для больших чисел — детерминированный тест Миллера — Рабина.

**Реализация.** Сервер на `gen_tcp`, для каждого клиента создаётся отдельный процесс Erlang. Клиент читает числа с консоли, отправляет их и выводит ответы.

## Реализация

- Сервер открывает порт через `gen_tcp:listen` в построчном режиме (`{packet, line}`) и в цикле принимает подключения. Для каждого клиента запускается отдельный процесс (`spawn`), сокет передаётся ему через `gen_tcp:controlling_process`, поэтому клиенты обслуживаются одновременно и независимо.
- Процесс клиента читает строку, вычисляет ответ, отправляет его и пишет запись в журнал сервера: `клиент 2: 91 -> COMPOSITE 7`.
- Для чисел меньше 10¹² делители проверяются перебором 2, 3 и чисел вида `6k ± 1` до целого квадратного корня (метод Ньютона). Ответ — наименьший делитель или `PRIME`.
- Для больших чисел сначала перебираются делители до 10⁶, затем выполняется тест Миллера — Рабина с основаниями 2…37. Он точен для всех чисел меньше 3.3·10²⁴. Если число составное, но маленький делитель не найден, ответ — `COMPOSITE` без делителя.
- Целые числа в Erlang не ограничены по размеру, поэтому числа больше 2⁶⁴ обрабатываются без переполнения.
- Клиент подключается через `gen_tcp:connect`, читает строки из консоли, отправляет их и печатает ответы. Если ввод идёт не с клавиатуры, а из конвейера, клиент повторяет каждый запрос в выводе (`> 97`). В конце ввода он отправляет `QUIT`.

Используется только стандартная библиотека Erlang/OTP.

## Окружение

- Erlang/OTP 24 или новее (проверено на OTP 29).
- Установка: [erlang.org/downloads](https://www.erlang.org/downloads), macOS — `brew install erlang`, Debian/Ubuntu — `sudo apt install erlang`.

## Запуск

Из каталога задачи:

```bash
erlc -o ebin src/prime_server.erl src/prime_client.erl
erl -noshell -pa ebin -s prime_server main 5001 > server.log &
printf "97\n91\n2\n1\n1000000007\nQUIT\n" | erl -noshell -pa ebin -s prime_client main localhost 5001
printf "18446744073709551557\n1000000016000000063\n49\n" | erl -noshell -pa ebin -s prime_client main localhost 5001
(printf "13\n15\n104729\n" | erl -noshell -pa ebin -s prime_client main localhost 5001 & printf "97\n91\n7919\n" | erl -noshell -pa ebin -s prime_client main localhost 5001 & wait)
cat server.log
erl -noshell -pa ebin -s prime_client main localhost 5001
```

Параметры:

- сервер: `main <порт>`;
- клиент: `main <хост> <порт>`; без конвейера числа вводятся с клавиатуры после приглашения `>`, выход — `QUIT` или Ctrl+D;
- остановить сервер: `kill %1` в том же терминале или Ctrl+C, если сервер запущен без `&`.

## Данные

Входные файлы не нужны: числа вводятся в клиенте.

| Запрос                 | Ответ                                              |
| ---------------------- | -------------------------------------------------- |
| `97`                   | `PRIME`                                            |
| `91`                   | `COMPOSITE 7`                                      |
| `1`, `0`               | `NEITHER`                                          |
| `1000000007`           | `PRIME`                                            |
| `18446744073709551557` | `PRIME` (наибольшее простое меньше 2⁶⁴)            |
| `1000000016000000063`  | `COMPOSITE` (произведение двух простых больше 10⁹) |
| `-5`                   | `ERROR negative number`                            |
| `abc`                  | `ERROR not an integer`                             |
