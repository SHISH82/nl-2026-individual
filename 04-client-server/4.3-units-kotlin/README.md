# 4.3. Сервер для конвертации единиц измерения (Kotlin)

## Постановка

Клиент отправляет запросы на перевод значения из одной единицы измерения в другую, сервер возвращает результат. Сервер и консольный клиент реализованы на одном языке, взаимодействие идёт по TCP, сервер обслуживает нескольких клиентов одновременно, порт задаётся аргументом командной строки.

**Категории единиц:**

- длина: `mm`, `cm`, `m`, `km`, `in`, `ft`, `mi`;
- масса: `g`, `kg`, `t`, `oz`, `lb`;
- температура: `C`, `F`, `K`;
- время: `s`, `min`, `h`, `day`.

**Протокол:**

- `CONVERT <значение> <из> <в>` → `OK <результат> <в>`;
- `LIST` → список поддерживаемых единиц по категориям;
- `QUIT` — завершение сеанса;
- при ошибке → `ERROR <описание>` (неизвестная единица, единицы из разных категорий, некорректное число, температура ниже абсолютного нуля).

**Реализация.** Линейные величины переводятся через базовую единицу категории, температура — по формулам. Сервер на `java.net.ServerSocket`, каждый клиент обслуживается в отдельном потоке.

## Реализация

- Таблица `units` сопоставляет каждой единице категорию и множитель к базовой единице категории: метр, килограмм, секунда.
- `convert` проверяет число и единицы. Для длины, массы и времени результат равен `значение · множитель_из / множитель_в`. Температура переводится через кельвины (`toKelvin`, `fromKelvin`), и значение ниже 0 K отклоняется.
- Результат округляется до 6 значащих цифр через `BigDecimal` и выводится без лишних нулей: `212`, `3.10686`, `86400`.
- `LIST` отвечает несколькими строками, по одной на категорию, и строкой `END`. Остальные команды отвечают одной строкой.
- Сервер и клиент находятся в одном файле и выбираются первым аргументом.
  - Сервер принимает подключения на `ServerSocket`, каждый клиент обслуживается в отдельном потоке (`thread { }`), номера клиентов выдаёт `AtomicInteger`. Каждый запрос записывается в журнал сервера.
  - Клиент читает команды с клавиатуры (с приглашением `>`) или из конвейера (тогда повторяет каждую команду в выводе), отправляет их и печатает ответы. В конце ввода он отправляет `QUIT`.
- Ввод и вывод через сокеты и консоль работают в кодировке UTF-8.

Используется только стандартная библиотека Kotlin и Java.

## Окружение

- Kotlin 1.9 или новее и JDK 17 или новее (проверено на Kotlin 2.4.21 и Temurin JDK 21).
- Установка: [kotlinlang.org/docs/command-line.html](https://kotlinlang.org/docs/command-line.html), macOS — `brew install kotlin`, Linux — через [SDKMAN](https://sdkman.io): `sdk install kotlin`.

## Запуск

Из каталога задачи:

```bash
kotlinc src/Units.kt -include-runtime -d bin/units.jar
java -jar bin/units.jar server 5003 > server.log &
printf "LIST\nCONVERT 100 C F\nCONVERT 5 km mi\nCONVERT 1 day s\nCONVERT 12 in ft\nCONVERT 2.5 kg lb\nCONVERT -40 F C\nQUIT\n" | java -jar bin/units.jar client localhost 5003
(printf "CONVERT 1 mi km\nCONVERT 30 C F\n" | java -jar bin/units.jar client localhost 5003 & printf "CONVERT 1 lb g\nCONVERT 90 min h\n" | java -jar bin/units.jar client localhost 5003 & wait)
cat server.log
java -jar bin/units.jar client localhost 5003
```

Параметры:

- `server <порт>` — запустить сервер;
- `client <хост> <порт>` — подключиться к серверу; без конвейера команды вводятся с клавиатуры после приглашения `>`, выход — `QUIT` или Ctrl+D;
- остановить сервер: `kill %1` в том же терминале или Ctrl+C, если сервер запущен без `&`.

## Данные

Входные файлы не нужны: команды вводятся в клиенте.

| Запрос               | Ответ                                       |
| -------------------- | ------------------------------------------- |
| `CONVERT 100 C F`    | `OK 212 F`                                  |
| `CONVERT 5 km mi`    | `OK 3.10686 mi`                             |
| `CONVERT 1 day s`    | `OK 86400 s`                                |
| `CONVERT 12 in ft`   | `OK 1 ft`                                   |
| `CONVERT 2.5 kg lb`  | `OK 5.51156 lb`                             |
| `CONVERT 1 kg m`     | `ERROR incompatible units: mass and length` |
| `CONVERT -300 C K`   | `ERROR below absolute zero`                 |
| `CONVERT abc m km`   | `ERROR invalid number`                      |
| `CONVERT 1 parsec m` | `ERROR unknown unit: parsec`                |
