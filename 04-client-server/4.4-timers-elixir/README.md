# 4.4. Сервер совместных таймеров обратного отсчёта (Elixir)

## Постановка

Сервер хранит именованные таймеры обратного отсчёта, общие для всех подключённых клиентов. Любой клиент может создать таймер, другие клиенты могут подписаться на него, управлять им и получить уведомление об окончании отсчёта. Сервер и консольный клиент реализованы на одном языке, взаимодействие идёт по TCP, сервер обслуживает нескольких клиентов одновременно, порт задаётся аргументом командной строки.

**Протокол:**

- `CREATE <имя> <секунды>` — создать и запустить таймер (создатель подписывается автоматически);
- `JOIN <имя>` — подписаться на таймер;
- `LEAVE <имя>` — отписаться;
- `STATUS <имя>` — оставшееся время и состояние;
- `PAUSE <имя>` / `RESUME <имя>` — приостановить и продолжить;
- `CANCEL <имя>` — отменить таймер (подписчики получают `CANCELLED <имя>`);
- `LIST` — список всех таймеров;
- по окончании отсчёта сервер рассылает всем подписчикам `DONE <имя>`.

**Реализация.** Каждый таймер — отдельный процесс, отсчёт через `Process.send_after`. Сервер на `:gen_tcp`, каждый клиент обслуживается своим процессом. Клиент принимает асинхронные уведомления от сервера одновременно с вводом команд.

**Обработка ошибок.** Повторное имя таймера, несуществующий таймер, некорректное время, отключение клиента (подписка снимается автоматически).

## Реализация

- `Timers` — реестр таймеров на основе `Agent`: словарь «имя → процесс». Проверка имени и создание таймера выполняются за один вызов `Agent.get_and_update`, поэтому два клиента не создадут таймер с одним именем.
- `CountdownTimer` — процесс `GenServer` для каждого таймера. Он хранит момент окончания, остаток при паузе, состояние и множество подписчиков.
  - Отсчёт идёт через `Process.send_after(self(), {:done, token}, ms)`. При паузе токен меняется, поэтому старое сообщение об окончании игнорируется. При продолжении отсчёт запускается заново на оставшееся время.
  - По окончании или отмене таймер рассылает подписчикам `{:notify, "DONE имя"}` или `CANCELLED`, удаляет себя из реестра и завершается.
  - Подписчики отслеживаются через `Process.monitor`: если клиент отключился, его процесс завершается, и таймер сам убирает его из подписчиков.
- Сервер принимает подключения через `:gen_tcp` и для каждого клиента запускает отдельный процесс. Сокет работает в режиме `active: :once`, поэтому один `receive` обрабатывает и строки от клиента, и уведомления от таймеров. Все запросы и уведомления записываются в журнал сервера.
- Клиент передаёт сокет отдельному процессу-читателю, который сразу печатает всё, что приходит от сервера, в том числе уведомления. Главный процесс в это время читает команды из консоли. Необязательное имя клиента выводится в начале каждой строки (`[Аня] DONE tea`), чтобы было видно, кому что пришло. Строка `sleep N` в клиенте — локальная пауза на N секунд, она нужна при вводе команд из конвейера.

Используется только стандартная библиотека Elixir и Erlang/OTP.

## Окружение

- Elixir 1.14 или новее и Erlang/OTP 25 или новее (проверено на Elixir 1.20.5 и OTP 29).
- Установка: [elixir-lang.org/install.html](https://elixir-lang.org/install.html), macOS — `brew install elixir`, Debian/Ubuntu — `sudo apt install elixir`.

## Запуск

Из каталога задачи:

```bash
elixir src/timer_server.exs 5004 > server.log &
(printf "CREATE tea 5\nsleep 7\n" | elixir src/timer_client.exs localhost 5004 Аня & sleep 1; printf "JOIN tea\nSTATUS tea\nsleep 6\n" | elixir src/timer_client.exs localhost 5004 Борис & wait)
printf "CREATE pizza 600\nCREATE tea 3\nLIST\nPAUSE pizza\nsleep 2\nSTATUS pizza\nRESUME pizza\nCANCEL pizza\nsleep 3\nLIST\n" | elixir src/timer_client.exs localhost 5004
(printf "CREATE soup 4\nsleep 6\n" | elixir src/timer_client.exs localhost 5004 Аня & sleep 1; printf "JOIN soup\nLEAVE soup\nsleep 5\n" | elixir src/timer_client.exs localhost 5004 Борис & wait)
cat server.log
elixir src/timer_client.exs localhost 5004 Аня
```

Параметры:

- сервер: `timer_server.exs <порт>`;
- клиент: `timer_client.exs <хост> <порт> [имя]`; без конвейера команды вводятся с клавиатуры после приглашения `>`, уведомления приходят в любой момент, выход — `QUIT` или Ctrl+D;
- остановить сервер: `kill %1` в том же терминале или Ctrl+C, если сервер запущен без `&`.

## Данные

Входные файлы не нужны: команды вводятся в клиенте.

| Команда                               | Ответ                                            |
| ------------------------------------- | ------------------------------------------------ |
| `CREATE tea 5`                        | `OK`, через 5 секунд всем подписчикам `DONE tea` |
| `JOIN tea`                            | `OK`                                             |
| `STATUS tea`                          | `tea 4s running`                                 |
| `PAUSE pizza`, затем `STATUS pizza`   | `OK`, `pizza 600s paused` (время не уменьшается) |
| `CANCEL pizza`                        | `OK`, подписчикам `CANCELLED pizza`              |
| `LIST`                                | таймеры с оставшимся временем или `NO TIMERS`    |
| `CREATE tea 10`, когда `tea` уже есть | `ERROR timer exists`                             |
| `STATUS coffee`                       | `ERROR no such timer`                            |
| `CREATE x -5`                         | `ERROR invalid time`                             |
